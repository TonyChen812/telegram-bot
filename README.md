# Nova AI Telegram Bot

Nova is an AI-powered Telegram bot built with Python, Flask, and Groq AI.

It can chat naturally, answer questions, search YouTube videos, provide real video links, and remember recent conversations.

---

## Features

- AI chat responses
- Conversation memory
- YouTube video search
- Real YouTube links
- Web search support
- Telegram commands
- Typing indicator
- Gunicorn deployment support
- Fake link filtering

---

## Commands

- `/start` — Start the bot
- `/help` — Show command list
- `/status` — Check bot uptime
- `/clear` — Clear AI memory

---

## Tech Stack

- Python
- Flask
- Groq API
- Telegram Bot API
- YouTube Data API v3
- Gunicorn

---

## Possible Problems

- AI may sometimes generate inaccurate responses.
- Web search results may occasionally be unreliable.
- Memory is temporary and resets after restart.
- The project is still under development.
